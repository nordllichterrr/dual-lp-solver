# Dual LP Solver

Решение прямой и двойственной задач линейного программирования
для варианта №15 практической работы №2 по дисциплине
«Теория систем и системный анализ».

## Постановка задачи

**Прямая задача (max):**

    3x1 + 4x2 + 2x3 -> max

при ограничениях:

    x1 + 4x2 + 2x3 <= 25
    2x1 + x2 + 3x3 <= 31
    x1 + 5x2 + x3 <= 37
    5x1 + x2 + 2x3 <= 39
    x1, x2, x3 >= 0

**Двойственная задача (min):**

    25y1 + 31y2 + 37y3 + 39y4 -> min

при ограничениях:

    y1 + 2y2 + y3 + 5y4 >= 3
    4y1 + y2 + 5y3 + y4 >= 4
    2y1 + 3y2 + y3 + 2y4 >= 2
    y1, y2, y3, y4 >= 0

## Запуск

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python dual_lp_solver.py

## Результат

- Оптимум прямой задачи (max):       35.0
- Оптимум двойственной задачи (min): 35.0
- Разрыв двойственности:             ~1e-15
